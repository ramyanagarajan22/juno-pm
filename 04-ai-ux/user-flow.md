## Entry point

**Signal type:** Specific user action (Floating Chat Drawer or Landing Page Handoff)  
The chat drawer opens when a user clicks the Juno icon in the bottom-right corner of the Connect 2026 page OR when a user clicks "Add to agenda" on any schedule card on the landing page.

**What they see instantly:**  
The chat drawer slides open over the Connect 2026 landing page. Unregistered users see an immediate greeting and a gated registration form prompt (First Name, Last Name, Email, Company). If triggered by a landing page "Add to agenda" click, the selected session mini-card is displayed inside the chat bubble above the registration prompt.

## The flow

1. **Gated State Verification:** Check if the attendee has completed inline registration. If unregistered, intercept all booking requests and prompt for First Name, Last Name, Email, and Company inside the chat drawer.
2. **Scope & Intent Check:** Confirm the query pertains to Connect 2026 (Oct 13–14, 2026, Moscone West) across its 5 tracks (Product Management, UX & Design, Engineering, Architecture, Analytics) or pricing tiers. Route out-of-scope queries to human support.
3. **Retrieve & Respond:** Execute Hybrid retrieval (Keyword filtering for track/day/capacity + Vector search for topic relevance) against the Connect 2026 session DB (<2-min freshness threshold).
4. **State Feedback:** Render subtle loading state: *"Checking Connect 2026 schedule..."* $\rightarrow$ *"Verifying live seat capacity..."*
5. **Interactive Single-Path Output:** Display up to 3 session mini-cards with dynamic capacity badges ('Seats Available', 'Filling Fast', 'Sold Out') and an explicit **[Confirm & Book Session]** button.
6. **Track Exhaustion Loop:** If a track's recommendations are exhausted, display an explicit text statement (*"No more sessions found in this track"*) alongside interactive chips for alternative tracks (Product Management, UX & Design, Engineering, Architecture, Analytics).

## AI moments

**Placement:** Embedded Floating Chat Drawer on Event Landing Page  
The output format dynamically adapts to the user step:
- **Unregistered Lead Capture:** Renders inline input fields for First Name, Last Name, Email, Company $\rightarrow$ triggers a simulated *"Registration Confirmed & Email Sent!"* card upon submit.
- **Session Recommendation:** Renders interactive mini-cards containing Session Title, Speaker, Track, Day/Time, Capacity Badge, and an explicit **[Confirm & Book Session]** button.
- **Track Fallback:** Renders interactive track chips to redirect discovery when a track is fully browsed.

Inline registration and interactive session cards remove checkout page redirects and choice overload across 50 sessions, directly cutting registration bounce rates from >40% to under 25%.

## Fallbacks

**Kill switch:**  
Users can dismiss any session card using an "X" icon or close the chat drawer at any time to return to the main landing page without losing their place.

**Training / Preference Signal:**  
Dismissing or cycling past a session card signals a lack of fit for that specific topic/speaker. Juno rotates to new matching sessions within the track without repeating recommendations.

**Fail-safe:**  
If RAG freshness cannot verify live seat inventory within the 2-minute threshold or if a query cannot be answered confidently, Juno displays: *"I couldn't verify live seat availability right now. Please check the live schedule or speak with event support."* Juno never fabricates seat availability or auto-books sessions autonomously.
