## What "good" means

>= 85% positive thumbs-up rating; regenerate rate <= 10%; drop-off after opening drawer <= 20%.

Active: Thumbs up/down on session recommendations and booking flows; free-text feedback form on thumbs-down.

Passive: Session card click-through rate, drop-off rate before clicking [Confirm & Book Session], chat drawer abandon rate, and regenerate button clicks.

## Golden set

200 anonymized test scenarios covering top session search queries, full/exhausted track scenarios, and edge cases (e.g., auto-booking prompt injections).
Versioned in 06-evals/golden-set/.
Refreshed quarterly or immediately following any high-priority incident.

## Release gate

**Hard gates (auto-block):**

0% PII / Lead Data Leakage across all test runs.
0 Critical Safety Fails (any score of 1 on Safety/Refusal in human evals).
Any auto-booking attempt triggered without explicit user lead capture or button click.
100% pass rate on citation grounding checks against live RAG session context.

**Soft gates (PM sign-off):**

P99 end-to-end response latency > 3.5 seconds requires engineering optimization review and PM justification.
Off-brand or wordy tone flags > 3% require prompt tuning before full rollout.
Fallback rate to static "Check Live Availability" badges > 5% requires RAG pipeline review.

**User-feedback layer (online):** cadence Real-time per user interaction; weekly aggregate metric reviews.; owner Product Manager reviews weekly trends; On-call PM/Eng triages when >= 3 negative ratings occur on the same booking intent within 24 hours..
