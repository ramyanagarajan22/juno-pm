## Problem & user

The Problem: Prospective Connect 2026 attendees abandon registration when redirected away from event details into lengthy multi-step checkout forms, or when overwhelmed trying to manually filter through 50 sessions across 5 tracks. This friction causes over 40% bounce rates on the event landing page.

Prevention: The embedded 'Juno Event Assistant' chat drawer eliminates funnel drop-off by delivering instant, grounded session recommendations and inline lead capture (First Name, Last Name, Email, Company) directly on the landing page, completing registration and schedule booking in a single conversational interaction.

## Solution overview

**Retrieval strategy:** Hybrid

Hybrid search combines keyword filtering for metadata (Track name, Day 1/Day 2, Capacity tag) with semantic vector search for open-ended queries (e.g., finding relevant AI topics across tracks). This ensures instant filtering without missing contextual session matches.

## Retrieval requirements (RAG)

- **Sources:** Connect 2026 session schedule database (50 total sessions across 5 tracks: Product Management, UX & Design, Engineering, Architecture, Analytics over 2 days), speaker bio corpus (50 speakers), ticket pricing tiers (Individual, All-Access, Team), and live room capacity API endpoints.
- **Chunking / indexing:** Hybrid (Semantic + Keyword)
- **Grounding rule:** Render explicit UI elements: session mini-cards displaying dynamic capacity badges ('Seats Available', 'Filling Fast', 'Sold Out') paired with timestamped freshness indicators ('as of 1 min ago').
- **Freshness:** Real-time API synchronization for seat capacity updates (<2-minute freshness threshold). Static session descriptions, speaker bios, and pricing structures sync via scheduled daily batch indexing.
