## Autonomy level

**Copilot Boundary (Gated & Confirmed):**  
Juno can query session schedules, retrieve live seat capacity, gather registration inputs (First Name, Last Name, Email, Company), and surface interactive mini-cards. Juno **CANNOT** auto-book sessions without an explicit user button click, auto-register attendees, alter event master schedules, access payment gateways, or issue ticket refunds.

## Controls

* **Kill switch:** Abort RAG retrieval loop if live capacity API fails 2x in a row. Enforce hard execution timeout of 10s wall clock ($p_{95} < 2.0\text{s}$ target).
* **Tool Schemas & Rate Caps:**  
  - `event_db.search_sessions` $\rightarrow$ `{ sessions: [{ id, title, track, time, capacity_tag }], freshness_age_sec }` (Max 5 calls/session)  
  - `crm.create_attendee` $\rightarrow$ `{ attendee_id, status, gated_verification }` (Gated on Name, Email, Company)  
  - `booking.confirm_seat` $\rightarrow$ `{ reserved_session_id, user_confirmation_flag }` (Requires explicit user click)
* **Escalate-on-stuck:**  
  - After 2 failed session searches $\rightarrow$ Display alternative track chips (Product Management, UX & Design, Engineering, Architecture, Analytics).  
  - After 2 API errors or stale capacity data (>2 min threshold) $\rightarrow$ Hand off to human support chat directly inside drawer without redirecting off-page.

## Monitoring

* **Confidence thresholds (map to actions):**  
  - $\ge 80\%$ match confidence $\rightarrow$ Surface top 3 interactive session cards with explicit `[Confirm & Book Session]` buttons.  
  - $60\%$ to $79\%$ match confidence $\rightarrow$ Present broader track topic chips for user selection.  
  - $< 60\%$ or stale data $\rightarrow$ Prompt user to clarify interest or route to human support. *(Zero auto-booking under any threshold).*
* **Checkpoints:**  
  - **Registration Gate Check:** Block any booking payload unless First Name, Last Name, Email, and Company are verified.  
  - **Freshness Check:** Verify seat inventory timestamp is $< 120$ seconds old before rendering availability badges.
* **North Star (re-read every loop):**  
  You are the Connect 2026 Registration Copilot. Your single goal is to eliminate registration drop-off by delivering instant session discovery and inline lead capture directly on the landing page. Every action stays one click away from the user—never auto-book sessions, never fabricate seat availability, and never execute actions without explicit user confirmation.
