# Agent Workflow Spec (AWSpec) · Juno

_Module 5. Generated by `M5 - Agent Workflow Spec Builder.html`. Paste over `05-agentic-workflows/awspec.md`._

## Goal

Assist prospective attendees by converting event inquiries into completed registrations and presenting interactive session recommendations for one-click agenda booking.

**Primary actor:** Agent + Human-in-the-loop

## Trigger

Prospective attendee opens the Juno chat drawer on the Connect 2026 page OR clicks "Add to agenda" on any landing page schedule card.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Read query or landing page handoff context and check attendee registration status. | crm.check_attendee_status(email: string) · scope: read-only | Agent can READ Connect 2026 Session DB and WRITE to Lead Capture CRM and Seat Reservation System upon explicit user button clicks. CANNOT auto-book sessions, modify master event schedules, edit existing attendee profiles, access payment gateways, or delete session records. |
| 2 | Query Connect 2026 DB for sessions matching requested track/topic. | event_db.search_sessions(track: string, query: string) · scope: read-only |  |
| 3 | Render inline registration form OR surface top 3 session mini-cards with live capacity badges. | ui.render_interactive_card(cards: array) · scope: client-render |  |
| 4 | Capture user lead inputs or process explicit user button click for session booking. | crm.create_attendee(first_name: string, last_name: string, email: string, company: string) · scope: write-only |  |
| 5 | Trigger email confirmation inside drawer and log conversion event. | booking.confirm_seat(attendee_id: string, session_id: string) · scope: write-only |  |
| 6 | _ | email.send_confirmation(attendee_id: string) · scope: write-only |  |

**Schemas**

event_db.search_sessions -> { sessions: [{ id, title, track, start_time, capacity_tag }], freshness_age_sec }. crm.create_attendee -> { attendee_id, status: "registered" }. booking.confirm_seat -> { reserved_session_id, user_confirmation_flag, status: "confirmed" }. email.send_confirmation -> { message_id, status: "sent" }.

**Memory (in or out of scope)**

- **Episodic:** In-scope: Chat history within active session, temporary lead capture form inputs; lifetime: end of browser session.
- **Semantic:** Out of scope: Do not persist long-term user preferences or attendee profiles across future event campaigns beyond this single Connect 2026 registration flow.
- **Working:** In-scope: In-flight variables (First Name, Last Name, Email, Company, Track Interest), generated Attendee ID, selected Session IDs.
- **External:** Connect 2026 Schedule DB (read-only), Lead Capture CRM (write-only), Seat Reservation System (write-only on user click), Email Service API (write-only).

## Human-in-the-loop

Control passes back to the human to complete missing registration fields (First Name, Last Name, Email, Company), select alternative tracks if sessions are full, or explicitly click [Confirm & Book Session].

## Success & failure

- **Done when:** Success: Attendee registered inline and session reserved via explicit user button click. Failure/Escalation: Live capacity API offline, unverified data (>120s old), or API failure 2x in a row. Timeout: Inactive chat drawer session for >10 minutes.
- **Fails safe when:** Agent can READ Connect 2026 Session DB and WRITE to Lead Capture CRM and Seat Reservation System upon explicit user button clicks. CANNOT auto-book sessions, modify master event schedules, edit existing attendee profiles, access payment gateways, or delete session records.
